# Acceptance First

## Existing acceptance criteria

The maintainer's work order for this repository is the source of truth. It requires a portable, sanitized repository; migrated tests; English and Traditional Chinese documentation; three-track TDD/BDD/GDD verification; a positive-control sanitization scan; one local commit; and no remote or push.

## What is being built

An installable, issue-ready open-source edition of the harness-retro safety workflow, with centralized configuration, synthetic incident examples, tests, CI, contributor materials, and honest optional-dependency degradation.

## Executable definition of done

`python3 -m pytest -q` passes; clean-HOME CLI smoke tests return without tracebacks; documented station order equals the program's `ALL_STATIONS`; the required repository scan is zero or every retained hit is justified; and the positive control is detected and removed.

## Size limit

One repository, one implementation package, migrated source tests plus only focused portability tests, 10–12 synthetic incidents, the requested documentation set, and no runtime artifacts or private incident corpus.
